# Full Stack Development Examples

Runnable examples for questions 3-10. Examples 3 and 4 use plain JavaScript and need no dependencies.

- `3-js-arrays-functions`: Student list webpage demonstrating JavaScript arrays and functions. Open `index.html`.
- `4-dynamic-webpage`: Browser-based student roster with dynamic add, search, and remove interactions. Open `index.html`.
- `5-node-modules`: Node.js ES module imports and exports. Run `npm start`.
- `q7-react-components`: React function and class components. Run `npm install`, then `npm run dev`.
- `q8-json-server`: React UI demonstrating GET, POST, PUT, PATCH, and DELETE with JSON Server. Run `npm install`, then start `npm run api` and `npm run dev` in separate terminals.
- `q9-mongodb-crud`: Express and Mongoose CRUD API. Start MongoDB, then run `npm install` and `npm start`.
- `q10-task-manager`: Full-stack React + Express + MongoDB task manager. Start MongoDB; install and run the backend and frontend separately. See its README.

Mongo-backed examples use `mongodb://127.0.0.1:27017` by default. Set `MONGODB_URI` to use a different MongoDB connection string.
